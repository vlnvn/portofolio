# V2 Reference Synthesis

This synthesis records principles used for the V2 Figma checkpoint. The portfolio does not copy the sources' visual identities, layouts, or branded assets.

## Bruno Simon

**SOURCE**  
https://bruno-simon.com/

**PRINCIPLE**  
An interactive 3D element can be part of the evidence when its behavior shows technical control.

**WHY IT FITS**  
The Signal Form is one continuous actor whose state helps explain movement between project chapters. It must remain useful when motion is disabled.

**WHAT NOT COPIED**  
The game world, vehicle interaction, environment, navigation model, or visual style.

## Robin Noguier

**SOURCE**  
https://robin-noguier.com/

**PRINCIPLE**  
Personal identity can share the same composition as the work instead of sitting in a separate profile card.

**WHY IT FITS**  
The real portrait, name, and Signal Form occupy one hero field. The result should feel authored while the factual introduction remains legible.

**WHAT NOT COPIED**  
Specific compositions, typography, imagery, or transitions.

## Natalie Almosa

**SOURCE**  
https://nataliealmosa.ca/

**PRINCIPLE**  
Playful manipulation can carry personality when the professional work stays easy to inspect.

**WHY IT FITS**  
V2 allows high visual variance around a structured evidence core. Interaction must reveal chapter state, not hide project facts.

**WHAT NOT COPIED**  
Personal artifacts, illustrations, colors, or interaction mechanics.

## Karina Sirqueira

**SOURCE**

## William Bout

**SOURCE**  
https://williambout.com/

**PRINCIPLE**  
A continuous visual feed can connect different kinds of work without forcing each item into the same card.

**WHY IT FITS**  
The five projects will become chapters with different rhythms. The Signal Form and adaptive navigation provide continuity.

**WHAT NOT COPIED**  
The feed layout, project crops, or page behavior.

## Webflow Brand and Design-System Guidance

**SOURCE**  
https://brand.webflow.com/  
https://brand.webflow.com/brand-assets  
https://university.webflow.com/resources/design-system-checklist

**PRINCIPLE**  
Use a confident blue identity with semantic tokens, and tie motion to real actions such as scrolling or swiping.

**WHY IT FITS**  
Dusty slate-blue defines V2, while electric and ice blue are reserved for energy, focus, and state change. A small token set keeps light and dark modes coherent.

**WHAT NOT COPIED**  
Webflow blue, logo, type, product layouts, or branded motion.

## Lottielab

**SOURCE**  
https://docs.lottielab.com/  
https://docs.lottielab.com/editor/animating

**PRINCIPLE**  
Describe motion as named states and transitions, then plan export and fallback behavior.

**WHY IT FITS**  
The storyboard defines resting, transition, settled, and release states. Mobile and reduced-motion modes receive deliberate poster states.

**WHAT NOT COPIED**  
The editor interface, templates, or stock animations.
